# Grands Sites de France : ce qui manque encore, et pourquoi.
#
# Le label vient de DEUX sources, et c'est voulu : la propriété Wikidata
# Q1154112 n'en trouve que dix-neuf — « Wikidata est ici en retard sur la
# liste officielle, c'est une limite connue » (config/labels.yaml) — et
# grand-site-de-france.csv complète à la main. La collection en compte
# cinquante et un pour cinquante sites officiels, un site pouvant être
# représenté par plusieurs de ses composants.
#
# ⚠️ Le CSV est lu au FETCH, pas au build : y ajouter une ligne ne change
# rien tant que le thème du lieu n'a pas été recollecté.
#
#
# ── Corrigé ───────────────────────────────────────────────────────────────
#
#   Rocamadour  Q22939731 → Q382628
#       Le Q-id inscrit désignait la BASILIQUE Saint-Sauveur, pas le site.
#       Le label — et son bonus de vingt points — se posait donc sur une
#       église à l'intérieur du Grand Site, pendant que le village, qu'on
#       vient voir, n'était pas étiqueté.
#
# ── Ajoutés : au catalogue, mais absents de la liste ──────────────────────
#
#   Site d'Étretat        Q113840948  ┐ « Falaises d'Etretat, Côte d'Albâtre »
#   Porte d'Aval          Q17373121   ┘
#   Gorges de la Jonte    Q2051933      « Gorges du Tarn, de la Jonte… »
#   Dune Dewulf           Q26700542     « Dunes de Flandre »
#   Pont transbordeur     Q924757       « Estuaire de la Charente - Arsenal
#     de Rochefort                        de Rochefort » — décision du
#                                         curateur : le transbordeur
#                                         représente le site, plutôt que
#                                         d'aller chercher l'arsenal.
#
#   Deux entrées pour un même site officiel suit l'usage déjà en place :
#   Cap Blanc-Nez ET Cap Gris-Nez pour « Les Deux-Caps », Îles Sanguinaires
#   ET Pointe de la Parata pour un seul site.
#
#
# ── Absents du CATALOGUE : rien à étiqueter tant qu'ils n'existent pas ────
#
# Ce n'est pas un problème de label mais de collecte, et il se traite comme
# les œuvres monumentales : suggest-qids, puis probe, puis places.csv.
#
#   Baie de Somme        (80)   ÉPINGLÉE. Q1741383, thème dunes-marais,
#                               vérifiée sur probe : coordonnées présentes,
#                               aucune classe écartée. Ses classes — paysage
#                               culturel, baie, estuaire — ne sont déclarées
#                               par aucun thème, d'où l'épinglage. Les autres
#                               candidats étaient des entités de PROTECTION
#                               (réserve naturelle, site Ramsar, parc
#                               régional), qui décrivent un statut et non un
#                               lieu ; deux autres étaient un bailleur social
#                               et une société de services — la recherche par
#                               préfixe ramasse les raisons sociales.
#
#                               ⚠ À VÉRIFIER après le build : Wikidata donne
#                               « Somme » pour commune, qui est le
#                               DÉPARTEMENT. Et le point tombe dans la baie,
#                               donc peut-être dans aucune commune — c'est le
#                               cas de la plage de Pampelonne, pour lequel la
#                               passe de rattrapage par azimuts existe.
#
#   Havre du Payré       (85)   ABANDONNÉ, et c'est une décision, pas un
#                               échec de recherche. Les trois termes ont été
#                               lancés. « Payré » ne rend que des communes de
#                               la Vienne, un nom de famille et un site
#                               archéologique de l'Ardèche.
#                               « Talmont-Saint-Hilaire » rend la COMMUNE, qui
#                               n'est ni le site ni un village de caractère.
#                               « Le Veillon » rend Q108076419, un terrain du
#                               Conservatoire du Littoral dont `probe` dit
#                               tout :
#
#                                   coordonnées : — AUCUNE —
#                                   langues : 0 · article francophone : non
#                                   classes : aire protégée (Q473972)
#
#                               On peut lui porter des coordonnées à la main,
#                               `probe` le propose. Mais la fiche n'aurait ni
#                               résumé ni photo, et son libellé serait celui
#                               d'un acte d'acquisition. La Pointe de la
#                               Courte Dune, entité du même import, est déjà
#                               au catalogue avec une langue, aucun résumé et
#                               un nom qu'il a fallu réécrire à la main : on
#                               sait donc à quoi ressemble ce qu'on ajouterait.
#
#                               Une fiche vide dans un guide vaut moins qu'un
#                               site manquant.
#
# Quarante-neuf des cinquante sites officiels ont donc un représentant, pour
# une liste que la propriété Wikidata seule ne connaît qu'à dix-neuf.
#
# Deux autres sont réglés SANS collecte, par le même raisonnement que le pont
# transbordeur : le catalogue possédait déjà un composant du site.
#
#   Marais de Brouage    (17)   Brouage (Q3308728, 99,6 pts), le village
#                               fortifié au cœur du marais.
#   Ocres du Luberon     (84)   Roussillon (Q321139, 148 pts), le village
#                               des ocres. Le Colorado provençal de Rustrel
#                               (Q2984389) est un second composant possible,
#                               absent du catalogue — à ajouter si l'on veut
#                               le site en deux fiches.
#
# Et un était un FAUX problème, comme le Concors : les gorges de la Cesse et
# du Brian n'ont pas d'entité Wikidata, mais leur site officiel s'appelle
# « Cité de Minerve, Gorges de la Cesse et du Brian » — et Minerve (Q660013)
# est étiquetée depuis toujours. Le site est représenté.
#
